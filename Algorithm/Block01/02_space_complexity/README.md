# Space Complexity — 空间复杂度

[← 返回 Block 01](../README.md)

## 1. 本课概览

上一课我们问：

> 程序要做多少工作？

这一课换一个角度：

> **随着数据规模 `n` 增加，算法额外需要多少存储空间？**

本课继续使用“寻找最大值”这个熟悉的问题，但把重点放在函数参数和额外变量上。

完成本课后，应能够：

- 理解空间复杂度关注的增长关系；
- 建立 `O(1)` 与 `O(n)` 额外空间的直觉；
- 区分输入本身占用的存储与算法额外申请的空间；
- 理解 `const std::vector<int>&` 为什么不会复制整个数组；
- 解释当前 `findMax` 为什么只需要 `O(1)` 辅助空间。

---

## 2. 直觉 / Intuition

假设一个算法处理 10 个数字，只额外使用：

```text
max
index
```

如果数据增加到 100000 个，这两个变量仍然只有两个。

这种额外空间不会跟 `n` 一起增加，可以看作：

```text
O(1)
```

但如果算法为了处理 `n` 个输入，又创建一个新的长度为 `n` 的数组，那么新增存储就会随着 `n` 增长：

```text
O(n)
```

所以空间复杂度问的是：

> **数据变大以后，我为了运行这个算法还需要额外保存多少东西？**

---

## 3. 核心思想 / Core Idea

本课最重要的区分是：

### 输入数据本身

当前 `main.cpp` 中：

```cpp
std::vector<int> nums;
```

保存了用户输入的 `n` 个整数。

这部分存储本身随 `n` 增长。

### 算法的辅助空间

`findMax` 的核心是：

```cpp
int findMax(const std::vector<int>& nums)
{
    int max = nums[0];
    ...
}
```

函数内部没有再创建一个长度为 `n` 的新数组，只使用了固定数量的变量。

更关键的是参数：

```cpp
const std::vector<int>& nums
```

这里使用引用 `&`，不会为了调用函数再复制一整个 `vector`。

因此，如果我们分析 `findMax` 的**辅助空间**，它是：

```text
O(1)
```

---

## 4. 手推 / Hand Simulation

假设：

```text
nums = [8, 3, 10, 4, 6]
```

无论数组有 5 个元素还是 50000 个元素，`findMax` 在扫描时始终只需要类似这些状态：

```text
当前下标 i
当前最大值 max
```

数组变大后，循环会执行更多次，所以时间会增长。

但这两个辅助变量的数量不会跟着增长。

这正是：

> **时间复杂度和空间复杂度是两个不同维度。**

---

## 5. 实现 / Implementation

本课真实代码：[`main.cpp`](./main.cpp)。

核心函数：

```cpp
int findMax(const std::vector<int>& nums)
{
    int max = nums[0];
    for (std::size_t i = 1; i < nums.size(); i++)
    {
        if (nums[i] > max)
        {
            max = nums[i];
        }
    }
    return max;
}
```

这里值得观察两件事：

1. `const`：函数只读取 `nums`，不修改它；
2. `&`：通过引用访问原数组，不复制整个 `vector`。

如果把参数写成按值传递：

```cpp
std::vector<int> nums
```

调用函数时通常需要复制整个数组，这会引入与 `n` 有关的额外成本。

---

## 6. 复杂度 / Complexity

### `findMax`

| 项目 | 复杂度 | 原因 |
| --- | --- | --- |
| 时间 | `O(n)` | 最坏情况下需要扫描整个数组 |
| 辅助空间 | `O(1)` | 只使用固定数量的额外变量 |

### 整个当前程序

程序本身需要保存 `n` 个输入，因此总存储会包含一个 `O(n)` 的 `vector`。

但在算法分析中，我们常常还会单独关心：除了输入本身，算法又额外申请了多少空间？

---

## 7. 常见错误 / Common Mistakes

- 看到 `vector` 就直接说辅助空间是 `O(n)`；
- 忽略按值传参可能产生副本；
- 把时间复杂度和空间复杂度混在一起。
