# Strings — 字符串

[← 返回 Block 01](../README.md)

## 1. 本课概览

字符串可以先把它理解成：

> **一串按顺序排列的字符。**

因此很多数组思维可以直接迁移过来：按下标访问、遍历、从两端向中间移动。

本课真实练习覆盖过：

- 已知下标访问字符；
- 遍历整个字符串；
- 统计某个字符出现次数；
- 原地反转字符串；
- 判断一个字符串是否为回文。

当前 `main.cpp` 最终运行的是回文判断。

---

## 2. 直觉 / Intuition

假设：

```text
s = "level"
```

如果要判断它是不是回文，最直接的观察是：

```text
第一个字符 == 最后一个字符
第二个字符 == 倒数第二个字符
...
```

我们没有必要把字符串重新复制一份再反转后比较。

只要从两端向中间检查即可。

这和上一课的数组原地反转很像：

> 左边位置和右边位置之间存在明确的对应关系。

---

## 3. 核心思想 / Core Idea

### 下标访问

```cpp
s[i]
```

已知位置时可以直接访问，因此通常看作 `O(1)`。

### 遍历与统计

如果要打印所有字符，或者统计某个字符出现了多少次，最坏都需要看完整个字符串：`O(n)`。

### 回文判断

对于长度为 `n` 的字符串，只需要比较前后对应字符：

```text
i
n - 1 - i
```

最多检查一半位置。如果发现任意一对不相等，可以立刻返回 `false`；如果所有对应位置都相等，则返回 `true`。

---

## 4. 手推 / Hand Simulation

以 `s = "radar"` 为例。

第一次：`s[0] = 'r'`, `s[4] = 'r'`，相等，继续。

第二次：`s[1] = 'a'`, `s[3] = 'a'`，相等，继续。

中间字符 `s[2] = 'd'` 不需要和自己比较。

因此只需检查到 `s.size() / 2` 即可。

再看 `s = "hello"`，第一对 `'h' != 'o'`，马上就能返回 `false`。

---

## 5. 实现 / Implementation

本课真实代码：[`main.cpp`](./main.cpp)。

当前核心实现：

```cpp
bool isPalindrome(const std::string& s)
{
    for (std::size_t i = 0; i < s.size() / 2; i++)
    {
        if (s[i] != s[s.size() - 1 - i])
        {
            return false;
        }
    }
    return true;
}
```

几个重要点：

- `const std::string&`：只读原字符串，不复制；
- `i < s.size() / 2`：只需要检查一半；
- 一旦发现不匹配，立即返回 `false`；
- 所有对应字符都通过后才返回 `true`。

同一文件中还保留了之前的 `printString`、`countChar`、`reverseString`，记录了真实学习过程。

## 6. 复杂度 / Complexity

| 操作 | 时间复杂度 | 辅助空间 |
| --- | --- | --- |
| 已知下标访问字符 | `O(1)` | `O(1)` |
| 遍历字符串 | `O(n)` | `O(1)` |
| 统计字符次数 | `O(n)` | `O(1)` |
| 原地反转 | `O(n)` | `O(1)` |
| 回文判断（最坏） | `O(n)` | `O(1)` |

回文判断虽然最多比较约 `n/2` 次，但忽略常数后仍然是 `O(n)`。

---

## 7. 常见错误 / Common Mistakes

- 右侧下标写成 `size - i`；
- 为判断回文额外创建反转副本；
- 忘记发现不匹配后提前返回；
- 把“检查一半”误认为复杂度是 `O(n/2)`。
